# Identidade visual — Sutoorii Tickets

A identidade aprovada usa o símbolo de ticket roxo com o “S” central.

Arquivos de produção:
- `public/icons/sutoorii-tickets-icon.svg`: símbolo vetorial do sistema.
- `public/brand/sutoorii-tickets-logo.svg`: logotipo completo.
- `public/icons/sutoorii-tickets-icon-512.png`: gerado no CI/deploy por `scripts/generate-brand-assets.php`.

O PNG é utilizado pelo PWA, notificações push e como foto de perfil da instância oficial do WhatsApp.
